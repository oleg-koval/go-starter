# Security Policy

## Supported versions

Only the latest release is actively supported with security fixes.

## Reporting a vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please report security issues by emailing **oleg.koval@pm.me** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact

You will receive a response within 48 hours. If the issue is confirmed, a patch will be
released as soon as possible depending on severity.
